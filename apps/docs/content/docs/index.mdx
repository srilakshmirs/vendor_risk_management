**VRM Intelligence** is the submission for the [Société Générale Third-Party Vendor Risk Management hackathon](https://societegenerale.iamneo.ai/third-party-vendor-risk-management/) — **Option A: AI-Powered Vendor Intelligence**.

It is a full-stack application that ingests 400 vendors, scores them continuously with a 5-component composite model, surfaces critical anomalies through 5 scheduled jobs, and exposes an LLM-driven analyst over the portfolio that can answer auditor questions in real time with cited sources.

## Rubric scorecard — 5 / 5 measured

The hackathon brief specifies five judged metrics. All five pass, with numbers measured against the provided `vendor_labels.csv` ground truth.

| Metric | Target | **Measured** |
|---|---|---|
| Vendor coverage | ≥ 95% | **100%** (400 / 400) |
| Risk-assessment accuracy | ≥ 80% | **90% anomaly · 100% CRITICAL recall · 100% HIGH recall · F1 1.000** |
| Alert lead time | ≥ 30 days | **60 / 30 / 7-day cascade** |
| Q&A response time | ≤ 5 min | **~3 s on Ollama · ~1 s on Claude Haiku** |
| Audit report generation | ≤ 15 min | **~250 ms per PDF** |

> Reproduce these numbers: `make eval` (full ASCII report) · `make eval-json` (machine-readable) · `pytest -k rubric` (regression-gated; CI fails if any metric drops).
